# Notes

A lightweight, single-page notes app built with vanilla HTML, CSS, and JavaScript. Create, edit, and organize notes right in the browser — no build step, no dependencies, no account required.

## Live demo

https://pryank18.github.io/notes-app/

## What it does

- **Create and edit notes instantly** — no save button, changes persist as you type
- **Search** — filter notes by title/content from the sidebar
- **Clean, distraction-free editor** — single-column layout focused on writing
- **Light/dark theme toggle**
- **Local persistence** — notes are stored in the browser, so nothing is lost on refresh
