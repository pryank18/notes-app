# notes-app

A lightweight, single-page notes app built with vanilla HTML, CSS, and JavaScript. Create, edit, and organize notes right in the browser — no build step, no dependencies.

**Live demo:** https://pryank18.github.io/notes-app/

## Features
- Create and edit notes instantly
- Clean, distraction-free interface
- Runs entirely client-side — no backend required

## Tech stack
Vanilla JavaScript, HTML, CSS
